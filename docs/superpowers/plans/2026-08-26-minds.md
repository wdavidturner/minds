# Minds Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship an early-alpha Cloudflare app where a Directory Think agent indexes isolated Mind Think agents that ponder in multi-thought sessions, accept queue/force/talk, and publish a public thought graph.

**Architecture:** Pure TypeScript modules own `decideBrief`, legal outcomes, outcome application, and the session loop (injectable store + model). A Worker routes public HTML and operator POSTs. Two SQLite-backed Think Durable Objects — `Directory` (instance `main`) and `Mind` (one instance per slug) — persist data, tools, and alarms. Minds never call other Minds.

**Tech Stack:** Cloudflare Workers, Durable Objects, `@cloudflare/think`, `agents`, Workers AI (`workers-ai-provider` + `ai`), Zod, Vitest (Node) for pure modules, Wrangler for types and deploy.

**Spec:** `docs/superpowers/specs/2026-08-26-minds-design.md`

## Global Constraints

- No topic strings in source (no “family hub”); cores are operator data. README may use family hub as an example create.
- Workers AI only; pin default model in env (`MODEL`), not in topic code.
- `OPERATOR_TOKEN` Worker secret; public routes unauthenticated; operator routes and agent WS require the token.
- Temperament four floats default `0.5`; store and list them; do not change session math in v1.
- Minds must not `getAgentByName` another Mind. Only Directory bootstraps Minds.
- Compatibility: `nodejs_compat` plus Think’s `experimental` flag. Do not enable `experimentalDecorators`.
- Minimum 8 thoughts per session (loop must accept a lower override in tests). Relate dig cap 4. Hot sleep 45s, idle sleep 720s.
- Do not port `shellm`. Workspace bash is files-only; research is `fetch_url`.

  distanceToCore: number;
  parentId: string | null;

export type SessionStore = {
  snapshot(): MindSnapshot;
  startSession(brief: BriefType, lineageId: string | null): string;
  recordThought(sessionId: string, thought: ThoughtRecord): string;
  apply(result: ApplyResult, sessionId: string): void;
  setWake(seconds: number): void;
  recentLine(lineageId: string | null): string;
  legalUnderlyingBrief(): BriefType | undefined;
  activeLineageId(): string | null;
  createLineageFromSuggestion(suggestionId: string): string;
  pickQueuedSuggestionId(): string | null;
};

export type ModelStep = (input: {
  brief: BriefType;
  legal: Outcome[];
  recent: string;
  thoughtCount: number;
  elapsedMs: number;
  remainingMs: number;
  windDown: boolean;
}) => Promise<{
  thought: ThoughtRecord;
  outcome?: Outcome;
  agendaTexts?: string[];
  suggestionId?: string;
  endSession?: boolean;
}>;

export async function runSession(
  store: SessionStore,
  model: ModelStep,
  now: () => number,
  opts?: { minThoughts?: number; alarmWallMs?: number; windDownMs?: number },
): Promise<{ sessionId: string; brief: BriefType; thoughtCount: number; outcome: Outcome }>

- [ ] **Step 3: Implement `runSession`**

```
brief = decideBrief(store.snapshot())
sessionId = store.startSession(brief, store.activeLineageId())
start = now()
outcome: Outcome | undefined
count = 0
loop:
  remaining = alarmWallMs - (now()-start)
  windDown = remaining <= windDownMs
  legal = legalOutcomes(brief, { underlyingBrief: store.legalUnderlyingBrief(), lineageStatus: snapshot.activeLineage?.status })
  step = await model({ brief, legal, recent: store.recentLine(...), thoughtCount: count, elapsedMs, remainingMs: remaining, windDown })
  store.recordThought(...)
  count++
  if step.outcome === 'select_suggestion':
    id = step.suggestionId ?? store.pickQueuedSuggestionId()
    store.createLineageFromSuggestion(id)
    store.apply(applyOutcome({ outcome: 'select_suggestion', brief, activeLineageId: ... }))
    brief = 'relate'
    continue
  if step.outcome === 'ignore_inbox':
    brief = 'grow_frontier'
    continue
  if step.outcome && legal.includes(step.outcome):
    if mayEndSession(...) or outcome is select/ignore (already handled):
      store.apply(applyOutcome(...))
      outcome = step.outcome
      break
  if step.endSession && mayEndSession(...):
    break
  if remaining <= 0: break
if !outcome: outcome = 'continue_line'; store.apply(applyOutcome({ outcome: 'continue_line', ... }))
store.setWake(nextWakeSeconds(...))
return { sessionId, brief, thoughtCount: count, outcome }
```

Never call another Mind. No network in this module.
